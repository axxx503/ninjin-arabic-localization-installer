# Ninjin: Clash of Carrots — تعريب عربي بالتثبيت المباشر

تعريب عربي موسّع لنسخة Windows، يضم ١٣١٥ قيمة نصية من ٤٧ ملف لغة، ويستخدم حروف الخط السعودي المصوّرة داخل اللعبة.

يشمل القوائم والإعدادات والحفظ واختيار الشخصيات والخريطة والمراحل والأعداء والمعدات والتلميحات والمتاجر وحوارات القصة والزعماء والنهاية ونصوص اللعب الجماعي.

**التثبيت:** أغلق اللعبة، افتح `Install-Arabic.exe`، اختر مجلد اللعبة واضغط «تثبيت التعريب». اختر **English** داخل اللعبة. لا يحتاج اللاعب إلى Python أو تنزيل أدوات أو خط منفصل أو اتصال بالإنترنت أثناء التركيب.

**الإزالة:** افتح المثبت نفسه بعد إغلاق اللعبة واضغط «إزالة التعريب». يحفظ الأصل تلقائيًا ويتحقق من البصمات قبل كل تعديل. لا يمس ملفات الحفظ.

**التوافق:** نسخة Windows المطابقة لبصمة الأصل في README_AR.md، باستخدام Unity 2019.4.21f1. يتوقف المثبت عند اختلاف النسخة أو وجود تعديل آخر مجهول.

**حالة النسخة 0.2.1:** اجتازت اختبارات البناء والمثبت والاسترجاع. أُصلحت صيغ اللاعبَين والمسافات في ١٦ نصًا إضافيًا. مراجعة جميع المشاهد وأوصاف المعدات الطويلة واللعب الجماعي فعليًا ما زالت مستمرة؛ لا ندّعي اختبارًا بصريًا كاملًا أو اكتمالًا بنسبة ١٠٠٪. الكتابة المدمجة في الصور والشعارات ليست ضمن هذا الإصدار.

المود غير رسمي. الحقوق الأصلية لأصحابها. ملف الخط TTF غير مرفق؛ المصدر والاتفاقية الرسمية موثقان في دليل الحزمة. لا تحتوي الحزمة الملف الكامل لأصول اللعبة أو ملفها التنفيذي؛ تطبق رقعة على نسخة اللاعب الأصلية.

عند الإبلاغ عن مشكلة، أرفق صورة واسم المرحلة أو القائمة وحالة اللاعب الواحد أو اللاعبَين.
